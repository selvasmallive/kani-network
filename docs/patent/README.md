# KANI Provisional Patent Documentation Package

This directory contains a working disclosure package for a U.S. provisional patent application relating to the KANI private settlement network.

This is not legal advice and is not a substitute for review by a USPTO-registered patent attorney or agent. It is an engineering disclosure package intended to give counsel a complete, concrete starting point.

## Files

```text
PROVISIONAL_SPECIFICATION_DRAFT.md
FIGURES.md
SANDBOX_MVP_EVIDENCE_APPENDIX.md
USPTO_FILING_WORKSHEET.md
```

## Suggested Use

1. Review inventor names, ownership, public-disclosure history, and title with patent counsel.
2. Convert the specification and figures into the format counsel prefers for Patent Center submission.
3. Have counsel decide whether to include the optional claim-style embodiments in the provisional.
4. File quickly if any GitHub repository, demo, website, investor deck, email, or public discussion has already disclosed the invention.
5. Calendar the nonprovisional/PCT deadline for 12 months after the provisional filing date.

## Engineering Scope Captured

The package covers:

- Private permissioned settlement network architecture.
- Tokenized fiat test assets and double-entry ledger controls.
- Proof-of-Authority validation with 2-of-3 finality metadata.
- Crypto-agile profile-driven signing and hashing design.
- ISO 20022 payment-message translation into ledger transactions.
- Sandbox compliance gating and audit/reporting surfaces.
- Cloud-native deployment patterns, including Cloud Run and GKE validator operations.
- End-to-end sandbox MVP evidence captured on May 10, 2026.
